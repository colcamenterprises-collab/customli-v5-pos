# Customli V5 POS

Standalone POS-only prototype based on the approved sushi reference screenshots. No V3 dependencies, dashboard, printer, KDS or CDS.

## Run

```sh
npm install
npm run dev
```

## Status

This is an initial frontend prototype, **not production-ready**. Orders exist only in browser memory, checkout is simulated, receipt is an on-screen confirmation, and product images are placeholders. No real payment processing, server-side persistence, or hardware integration is included.
